# GFE-75 Apps

A collection of frontend apps built as part of the GFE-75 project.

## Apps

- [Contact Form](Contact-Form-Q-7/README.md) - A React contact form implementation.
- [To-do List](to-do-list/README.md) - A simple to-do list app.
- [Accordion](accordian-q11/README.md) - An accessible React accordion for HTML, CSS, and JavaScript topics.
- [Dice Roller](dice-roller-q111/README.md) - A React and TypeScript app for rolling six-sided dice.
